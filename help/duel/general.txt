.duel/.duel!/.duel！/.决斗/.决斗！/.打牌/.打牌！/.牌/.牌！/.房
  ygo约战开房！
  通过指令生成房间代码，主要用于233和超先行服
  可以记录生成的房间代码，方便之后快捷调出
例：
  .duel 房 -t -tm 0
      => TM0,T#房
  .duel 房 -麻将 -时间 0
      => TM0,T#房（同上一条）
  .duelset 俺的房
      => 记录了房间【俺的房】
  .duel
      => 俺的房
  .duel -s 编年史
      => 决斗编年史的服务器信息
选项详细：
  详见 .help duel detail
